# 자금조달 상세 분석 패널

## 지원 범위

- 일반 회사채: `증권신고서(채무증권)`, `[발행조건확정]증권신고서(채무증권)`, 무보증사채·회사채 발행결정 계열
- 전환사채: `전환사채권발행결정`
- 신주인수권부사채: `신주인수권부사채권발행결정`
- 유상증자: `유상증자결정`, `증권신고서(지분증권)`

분류 순서는 CB·BW·EB를 일반 채무증권보다 먼저 검사해 메자닌이 일반 회사채로 잘못 분류되지 않게 한다. `[기재정정]`, `[첨부정정]`, `[발행조건확정]`, 철회·취소 표시는 원공시 제목과 분리해 연결한다.

## 데이터 흐름

1. OpenDART 원문을 텍스트로 변환한다.
2. 규칙 분석기가 DART 항목명에 연결된 값과 짧은 근거 구간을 추출한다.
3. 금액은 원문 숫자·단위·공시일을 함께 저장하고, 임의 환산이나 통화 추정을 하지 않는다.
4. 잠재 희석률은 `신규·잠재 발행주식 수 ÷ 증자 전 발행주식 수 × 100`으로 계산하며 분자·분모를 저장한다.
5. 검증기가 주요 숫자의 원문 근거와 희석률 계산을 다시 확인한다.
6. 정정본은 연결된 직전 공시와 비교해 실제 변경 필드만 저장한다.
7. 정적 생성기는 공시 유형별 필드만 패널에 표시하고, 원문이 없는 값은 만들지 않는다.

AI가 켜져 있어도 자금조달 숫자와 조건은 규칙 기반 결과를 사용한다. AI는 기존 요약·근거 설명을 보조하며, 호출 실패 시 전체 분석은 규칙 모드로 자동 전환된다.

## 화면 동작과 접근성

- 카드의 `DART 원문 보기` 옆에 대상 유형만 `핵심 분석 보기`가 표시된다.
- 데스크톱은 우측 패널, 720px 이하 화면은 전체 높이 모바일 패널을 사용한다.
- 닫기 버튼, `Escape`, 배경 클릭을 지원한다.
- 열기 버튼으로 포커스를 되돌리고, 열린 동안 포커스를 패널 안에 가둔다.
- 패널을 닫을 때 기존 스크롤 위치를 복원하며 필터·정렬 DOM 상태를 재생성하지 않는다.
- 공시 원문과 회사명 등 모든 외부 문자열은 HTML 이스케이프한다.

## 위험요인 표시 기준

위험 판단이 아니라 추출된 조건의 확인 신호다.

- 리픽싱: 관련 조건 문구가 추출된 경우
- 높은 잠재 희석률: 계산값이 20% 이상인 경우(화면 표시 기준)
- 단기 만기: 공시일로부터 365일 이내 만기인 경우
- 채무상환 목적: 자금용도 표에서 해당 항목과 금액이 추출된 경우
- 특수관계자 배정: 발행·배정 대상 문구에 최대주주, 대표이사, 특수관계 또는 관계회사 표시가 있는 경우

어느 조건도 자동 확인되지 않으면 위험이 없다고 단정하지 않고, 현재 추출 범위에서 별도 조건을 확인하지 못했다고 표시한다.

## 현재 한계

- DART 문서의 표 구조가 기업·시장·서식 버전에 따라 달라 자동 추출 확인 경고가 생길 수 있다.
- 담보·보증의 자유서술형 조건과 반복 발행 여부는 이번 단계에서 구조화하지 않는다.
- 회사채의 여러 트랜치가 한 문서에 포함된 경우 현재 모델은 대표 단일값 중심이다.
- 실브라우저 자동화는 CI에 브라우저 런타임이 있는 환경에서 추가 실행하는 것이 권장된다. 단위 테스트는 패널 제어 코드, 모바일 미디어 쿼리, 이스케이프 및 기존 필터·정렬 회귀를 검증한다.
